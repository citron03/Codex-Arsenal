## 👀 About

**Codex Arsenal**은 Codex 기반 개발 경험을 강화하기 위한 각종 리소스를 모아두는 저장소입니다.

단순히 “좋은 플러그인 리스트”가 아니라:

* 실제 개발자들이 많이 쓰는 Codex 플러그인
* Claude Code 스타일의 workflow enhancement
* productivity presets & configs
* agent skill collections
* prompt engineering examples
* terminal / editor integrations
* 실전 셋업 및 운영 팁

같은 것들을 한 곳에 정리하는 것을 목표로 합니다.

## ⭐ Philosophy

이 레포는 단순한 “awesome list”가 아닙니다.

가능하면 아래 기준을 만족하는 것들만 모읍니다.

* 실제 개발 생산성이 올라가는가?
* 실무에 적용 가능한가?
* 반복 사용성이 있는가?
* Codex의 한계를 보완하는가?
* setup 대비 효율이 좋은가?

## 🤝 Contributions

좋은 플러그인, 스킬, 설정, 프롬프트, workflow가 있다면 언제든 PR 환영합니다.

특히 아래 같은 것들을 좋아합니다:

* 실제로 오래 써본 것
* 생산성 체감이 큰 것
* setup 과정이 잘 정리된 것
* before / after 차이가 명확한 것

## 🌌 Vision

미래의 개발 환경은 단순 IDE + AI 수준이 아니라:

> “개발자가 여러 AI 에이전트를 orchestration 하는 환경”

에 가까워질 가능성이 높다고 생각합니다.

이 레포는 그런 방향성을 실험하고 기록하는 공간입니다.
